# 💬 Мессенджер

Full-stack веб-приложение для обмена сообщениями, разработанное с использованием React, Node.js, Express и PostgreSQL.

Проект создан для практического изучения full-stack-разработки: взаимодействия клиентской и серверной частей, работы с REST API, управления состоянием приложения и хранения данных в реляционной базе данных.

## ✨ Возможности

- **Регистрация и авторизация** — создание аккаунта и вход в систему.
- **Список пользователей** — получение и отображение зарегистрированных пользователей.
- **Создание чатов** — возможность начать переписку с другим пользователем.
- **Обмен сообщениями** — отправка сообщений и загрузка истории переписки.
- **Хранение данных** — сохранение пользователей, чатов и сообщений в PostgreSQL.
- **Последнее сообщение** — сохранение и отображение последнего сообщения в чате.

## 🏗️ Архитектура приложения

Приложение построено на основе клиент-серверной архитектуры.

1. Пользователь взаимодействует с интерфейсом React.
2. Frontend отправляет HTTP-запросы на сервер Express.
3. Backend обрабатывает запросы и выполняет необходимые операции с базой данных.
4. PostgreSQL хранит и возвращает данные.
5. Сервер отправляет клиенту JSON-ответ.
6. React обновляет состояние приложения и отображает актуальные данные.

## 🗄️ Структура базы данных

Основные сущности приложения:

- **Users** — данные пользователей.
- **Chats** — информация о переписках между пользователями.
- **Messages** — текст сообщений, отправитель, чат и время создания.

Для поддержания целостности данных используются внешние ключи, связывающие сообщения с чатами и пользователями.

## 🚀 Установка и запуск

### Требования

Перед запуском убедитесь, что у вас установлены:

- Node.js
- npm
- PostgreSQL
- Git

### 1. Клонирование репозитория

```bash
git clone <ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ>
cd <ПАПКА_ПРОЕКТА>
```

### 2. Установка зависимостей

Перейдите в директорию backend и установите зависимости:

```bash
npm install
```

Повторите установку в директории frontend, если у клиентской и серверной частей отдельные файлы `package.json`.

### 3. Настройка базы данных

Создайте базу данных PostgreSQL и выполните SQL-скрипты для создания необходимых таблиц.

Убедитесь, что настроены таблицы пользователей, чатов и сообщений, а также необходимые связи между ними.

### 4. Настройка переменных окружения

Создайте файл `.env` в директории backend.

Пример конфигурации:

```env
PORT=5000
DB_HOST=localhost
DB_PORT=5432
DB_NAME=messenger
DB_USER=имя_пользователя
DB_PASSWORD=ваш_пароль
```

Названия переменных должны соответствовать тем, которые используются в коде сервера.

**Важно:** не публикуйте файл `.env` и реальные пароли в репозитории.

### 5. Запуск приложения

Запустите backend и frontend в отдельных терминалах, используя команды, указанные в соответствующих `package.json`.

После запуска откройте локальный адрес frontend в браузере.
